# Generated Template Role Baselines

Files in this directory are generated from workbooks by
`hara_agent.template.TemplateRoleCompiler`.

They bind semantic roles to an immutable workbook `template_hash`. They do not
copy HARA engineering rules and are not customer-maintained business inputs.
If a workbook changes, its hash changes and the previous binding cannot be
reused. Unambiguous workbooks are compiled automatically; a human confirmation
is stored only when role discovery cannot uniquely select an existing region.
